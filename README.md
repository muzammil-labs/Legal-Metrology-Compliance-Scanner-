# PakkaLabel India — Legal Metrology Compliance Scanner (SIH26034)

Automated statutory label compliance scanner for packaged commodities under the Department of Consumer Affairs (DOCA), Government of India.

## Features
- **Multimodal AI & Deterministic Validation:** Verifies Rule 6(1)(a-f), Rule 6(11) Unit Sale Price math, and PDP font geometry according to Schedule II.
- **Section 36 PDF Generation:** Produces court-admissible notices with SHA-256 cryptographic chain of custody.
- **B2B Pre-Audit API:** Cloud pre-audit endpoint (`/api/v1/pre-audit`) for FMCG artwork validation.
- **Citizen Scanner & Field Inspector Views:** Responsive dark-mode interface with 1-click fallback demo fixtures.
